PREVIEW
Open index.html in any modern browser. Internet is only needed for the Google Fonts import; the website otherwise works locally.

PUBLISH WITH GITHUB PAGES
1. Create a new public GitHub repository (for example: arsany-portfolio).
2. Upload index.html, style.css, and script.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site and copy the generated URL.
